# KREVO PWA para iPhone

## Publicación con GitHub Pages
1. Crea un repositorio público `krevo`.
2. Sube todos estos archivos a la raíz.
3. GitHub → Settings → Pages → Deploy from a branch.
4. Branch `main`, carpeta `/ (root)`.
5. Abre la URL HTTPS en Safari.
6. Compartir → Agregar a pantalla de inicio.

No abras `index.html` desde un lector HTML si querés instalar la PWA. El selector de `.3mf` está pensado para Safari.
